# خزينك (ديمو)

ديمو لتطبيق طلب خزين البيت بدورة توصيل أسبوعية: واجهة عميل + لوحة تشغيل.

## التشغيل

```bash
npm install
npm run dev
```

وافتح http://localhost:3000 (لوحة التشغيل على `#admin`).

## أماكن التعديل

- `lib/data.ts`: الأصناف والأسعار وسعر الجملة، المناطق، الحد الأدنى، رسوم التوصيل، البنزين، وأوردرات الديمو.
- `lib/useCycle.ts`: ميعاد قفل الطلب ويوم التوصيل.
- `components/Storefront.tsx`: واجهة العميل وتأكيد الطلب.
- `components/Admin.tsx`: حساب الرحلة، قائمة الشراء، خط التوصيل.

الأسعار تقريبية، والأوردرات مولّدة ببذرة ثابتة، ومفيش باك إند: الطلب الجديد بيتحفظ في الذاكرة لحد ما الصفحة تتقفل.

نسخة ثابتة للرفع على أي استضافة: `STATIC_EXPORT=1 npm run build` والناتج في `out`.
